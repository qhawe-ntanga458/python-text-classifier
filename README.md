# Python Text Classifier

## About
A beginner Python project that classifies the sentiment of text as positive, negative, or neutral using keyword-based rules.

## Features
- Accepts sentences entered by the user.
- Identifies positive and negative keywords.
- Calculates positive and negative keyword scores.
- Classifies text as positive, negative, or neutral.
- Allows the user to enter multiple sentences.
- Provides an option to exit the program.

## Technologies
- Python
- Functions
- Lists
- String manipulation
- Conditional statements
- Loops
- User input and output

## How It Works
The program converts text to lowercase, checks for predefined positive and negative keywords, and compares the keyword scores to determine a sentiment category.

## Example
Input:
`I feel happy and great today!`

Expected classification:
`Positive`

Note: Results depend on the keywords recognised by the program. This is a basic rule-based classifier, not a trained AI model.

## Learning Goals
- Practise writing Python functions.
- Work with lists and strings.
- Use loops and conditional statements.
- Learn the basic concept of text classification.
